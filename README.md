# Asd_Reseau_Social
Projet d’analyse et d’exploration d’un réseau social. L’objectif est de concevoir et d’implémenter en langage C une structure de données représentant un réseau social sous forme de graphe pondéré, avec des fichiers .c et .h et des TDA. Le projet intègre les algorithmes DFS, BFS et Dijkstra.
